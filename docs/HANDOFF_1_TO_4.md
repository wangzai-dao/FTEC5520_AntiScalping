## 3. Interface List (6 core + common helpers)

| Function | Returns | Purpose |
|---|---|---|
| `get_ticket_owner(token_id)` | `str` address | Current owner of the ticket |
| `buy_ticket(event_id, buyer="buyerA", quantity=1)` | `TxResult` | Primary-market purchase; `extra` contains `first_token_id` |
| `list_ticket(token_id, price_eth, seller="buyerA")` | `TxResult` | Create a listing; the contract rejects prices above the dynamic cap |
| `buy_resale(token_id, buyer="buyerB")` | `TxResult` | Buy a resale ticket |
| `check_in(token_id, verifier="verifier")` | `TxResult` | On-chain check-in |
| `get_receipt(tx_hash)` | `dict` | Receipt: block / gas / status / timestamp |

Helpers: `get_event` `list_events` `get_ticket` `get_max_resale_price` `can_purchase`
`purchased_count` `remaining_supply` `tokens_of` `listed_tickets` `transfer_history`
`create_event` `set_whitelist` `set_event_active` `set_presale_active` `set_verifier`
`is_verifier` `get_chain_status` `signing_key` `pending_proceeds` `pending_platform_fees`
`withdraw_proceeds` `withdraw_platform_fees`.

The unified `TxResult` structure:

```python
TxResult(ok=True, function="purchaseTickets", tx_hash="0x…",
         block_number=44, gas_used=155012, status=1, from_address="0x…", error=None)
```

On failure `ok=False`, and `error` is the reason for the contract revert (the ABI-encoded hex string has already been stripped):

```
Not an authorized verifier
Price exceeds dynamic limit
Ticket already used
Wallet limit exceeded
```

## 6. Two Points of Caution for Member 4

1. **Do not make rule decisions inside the page** (for example, computing the price cap yourself). The cap is read from the on-chain result of `get_max_resale_price()`,
   and the contract is what actually enforces it; a wrong computation in the page only misleads users.
2. **Account private keys are used only for "server-side signing on behalf of the user" in the classroom Demo**. The report must state clearly that a real product should sign with the user's own wallet,
   and that the server should not hold user private keys. This notice is already displayed on the page.
